# 07 — data notes

The study uses **no external observational data**. All numbers come from simulation and from LLM answers generated by
the scripts in `code/`; every run is seeded.

| Input | Source | Licence / terms | How it is used |
|---|---|---|---|
| Bidding rules of the platform | ArtSphere Auction, the author's own diploma project, public repository https://github.com/MrGorenkov/ArtSphere-Auction (cloned outside this repo on 2026-09-25, commit `daded1a`) — files `backend/Sources/App/Controllers/BidController.swift`, `AuctionController.swift`, `database/init.sql` | author's own code | Rules reproduced in `code/auction.py`: minimum bid = max(current + step, starting price); auto-broker ("proxy") bids one step at a time, best maximum first, ties by earliest setting; **at most 50 ladder steps per trigger** (`maxLadderSteps = 50`); fixed end time; reserve price; buy-now price 2.5 × start (not modelled); outbid push notifications; offline bid queue whose bids are rejected after the close (motivates lost late bids) |
| Private values | drawn in `code/population.py`: U[0,1] (baseline), lognormal (median 0.5, σ = 0.5), Beta(1,3) | — | independent private values |
| LLM models | Qwen3.5 0.8B / 2B / 4B / 9B / 27B, GGUF Q4_K_M conversions by bartowski on Hugging Face (`bartowski/Qwen_Qwen3.5-<size>-GGUF`); base models `Qwen/Qwen3.5-*` | Apache-2.0 (Hugging Face API `cardData.license` of `Qwen/Qwen3.5-{0.8B,2B,4B,9B,27B}`, checked 2026-09-25) | bidding plans elicited by `code/llm_bidders.py` via llama.cpp `b11136` `llama-server` |

Nothing is downloaded into `data/raw/`; model files live outside the repository (`~/models`, ignored `*.gguf`).
